🚀 AI Projects Dashboard

A multi-project AI dashboard built with Streamlit that integrates multiple machine learning and AI applications into a single modern interface.

📌 Overview

This project combines multiple AI-powered systems into one centralized dashboard:

💻 Laptop Price Predictor
🔍 Lost & Found AI Search System
🎓 Smart FYP Team Matcher

The dashboard provides a clean UI, sidebar navigation, and modular architecture for easy scalability.

🚀 Installation
1️⃣ Clone Repository
git clone <your-repository-link>
cd AI_Dashboard
2️⃣ Create Virtual Environment
python -m venv venv

Activate environment:

Windows
venv\Scripts\activate
Linux / Mac
source venv/bin/activate
3️⃣ Install Dependencies
pip install -r requirements.txt
▶️ Run The Dashboard
streamlit run app.py
